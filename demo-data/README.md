# Synthetic demo data

## FileSync v1.0.0

`001_FileSync-inputs.zip` is the initial input for the current FileSync recording. Extract into a disposable writable folder. Select its **Folder A** and **Folder B**, choose **Mirror →** with destination deletion enabled, then Analyze. Each side has 1,000 text files: 700 identical, 100 reports to update, 200 new source notes and 200 obsolete destination notes. Run produces 300 copies/updates and 200 removals to trash.

Projects/Shared, Projects/Reports, Fieldwork and Archive contain nested batch folders. Padded synthetic text makes the compressed ZIP much smaller than its roughly 114 MiB extracted contents. Re-extract to a new folder before repeating; the first run removes the differences. See [the recording guide](../demo-tools/FileSync-recording.md) for generation and verification. The recording uses mapped demo folders; its timings are not an HDD benchmark.

## Historical five-app samples

synthetic-data-and-outputs.zip contains deterministic fixtures generated by demo-tools/make_fixtures.py and the example outputs produced by the recorded app runs.

| Folder | Contents |
| --- | --- |
| sync | Small text, CSV, and FASTA files in source/destination folders |
| binding | Candidate XLSX and a reference DNA sequence |
| hub | Three-row synthetic Primer Log with input addon sheet and sequence exports |
| peak | Three synthetic 160-base AB1 traces and processed output files |
| km | Synthetic 80-row survival cohort |
| exports | Results workbooks saved by the recorded workflows |

Every patient/sample/work identifier is synthetic. These inputs demonstrate formats and software behavior; they are not scientific benchmarks or clinical data. Outputs reflect the app versions used for the recordings, not a promise that later scientific algorithms produce identical results.
