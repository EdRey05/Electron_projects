## Locked decisions applied

Default Mode B searches one probe against database rows; Mode A preserves candidate screening against one reference. Ns are masked; coordinates identify their axis and use the original probe coordinates for reverse hits. Thresholds span 50–100%. Persistence is deferred. UniVec fetches run in Electron main with a seven-day portable cache and manual refresh. Analysis and export are separate actions.

The user approved testing the actual 3,155-entry UniVec_Core snapshot plus a clearly labeled 6,100-row benchmark because the spec's >5,000-entry assumption did not match the current official download. Database record count is not hardcoded.

## Current scope limits

Identity is ungapped best-window identity, not binding affinity, contamination abundance or BLAST significance. No circular wrapping, gaps, taxonomic classification or multi-probe batch mode. Excel sequence cells cap at 32,000 bases; full downloaded FASTA remains in memory/cache. Shared vector segments may yield multiple perfect database hits. New NCBI downloads need internet; cached and workbook searches run offline. Windows x64 is the supported portable target.
